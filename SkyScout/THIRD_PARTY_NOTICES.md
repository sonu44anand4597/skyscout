# Airport location and timezone data

`backend/data/airport-locations.json` is derived from the existing local
`ml/data/airportsdata-airports.csv` snapshot. The derived file records its input
SHA-256, source and derivation time. It is a static catalog, not a live airport
information service. Source: https://github.com/mborsetti/airportsdata

# Landing-page typography and image

`public/fonts/plus-jakarta-sans-*.woff2` contains Plus Jakarta Sans from Google
Fonts, distributed under the SIL Open Font License 1.1. The complete license and
copyright notice are retained in `public/fonts/OFL.txt`. Source:
https://github.com/google/fonts/tree/main/ofl/plusjakartasans

`src/assets/images/hero-aircraft-{768,1536}.webp` is AI-generated artwork created
for this project with the built-in OpenAI image-generation tool on 14 November
2026. It depicts an unbranded rendered passenger aircraft, rather than a photo of
a particular aircraft or airline. No third-party stock photograph was downloaded.
The generation prompt and optimization details are in `docs/hero-asset.md`.
